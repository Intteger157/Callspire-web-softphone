# softphone-web (SPA)

Place the **Callspire browser client** sources here (Vite, webpack, or your stack).

- Run `npm install` and `npm run build`.
- Output must be **`dist/`** at repo root **`softphone-web/dist`** — the BFF serves it from [`../softphone-bff/src/server.js`](../softphone-bff/src/server.js).

If this directory is empty in GitHub, the SPA lives in another branch or private checkout; clone it here before building.
